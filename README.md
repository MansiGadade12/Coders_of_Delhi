# Social Media Recommendation System

A Python-based project that analyzes social media user data and provides recommendations such as **People You May Know** and **Pages You Might Like**.

The project uses JSON data to store information about users, their friends, and the pages they have liked. Python is used for data loading, cleaning, analysis, and recommendation logic.

## 📌 Project Overview

The project simulates a simple social media recommendation system.

It analyzes:

- User information
- Friend connections
- Liked pages
- Common friends
- Commonly liked pages

Based on these interactions, the system recommends relevant users and pages.

## 🎯 Objectives

- Load and process data stored in JSON format.
- Identify and clean incorrect or incomplete records.
- Find friend recommendations.
- Recommend pages based on common interests.
- Understand the basic concept of collaborative filtering.
- Implement recommendation logic using Python.

## 🛠️ Technologies Used

- Python
- JSON
- Data Cleaning
- Sets and Dictionaries
- Collaborative Filtering
